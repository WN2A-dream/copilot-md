共通仕様

  • レスポンス形式: { content: [{ type: "text", text: string }], isError?: boolean }
  • 出力内容: stdout をそのまま返却し、stderr は [stderr] プレフィックス付きで追記する
  • 出力なし: (出力なし) を返却する
  • エラー判定: 終了コードが 0 以外、またはツール内部でバリデーションに失敗した場合に isError: true を返す
  • 作業ディレクトリ: 全ツール共通の必須パラメータ workingDirectory を使う。複数フォルダワークスペースでは共有制御ルートを指定する

構造化ファイルツール

構造化データファイル（JSON、YAML、XML、TOML、INI）を読み書きするツール群。全ツールで 10MB のファイルサイズ上限と、ワーキングディレクトリ外へのアクセス防止が適用される。

共通仕様

  • パス検証: workingDirectory 配下のみアクセス可能。パストラバーサルを防止
  • ファイルサイズ上限: 10MB
  • BOM対応: UTF-8 BOM を自動で除去して読み込み
  • プロトタイプ汚染対策: __proto__、constructor、prototype キーへのアクセスを禁止
