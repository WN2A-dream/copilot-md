タスクモード

orchestrator はタスク種別に応じて4つのモードを使い分ける。

モード 概要 主なフロー
setup ドキュメント整備、初期設定 investigator → planner → documenter
design 要件ヒアリング、設計検討 interviewer → planner
investigation コードベース調査のみ investigator
development コード実装・修正 investigator → planner → developer → tester → reviewer → documenter

MCP サーバーアーキテクチャ

local-command MCP サーバーは、シェルコマンド実行・管理領域書き込み・Markdown 変換・構造化データファイル操作・ウィンドウ操作を構造化パラメータで提供する。

技術スタック

項目 選定 理由
実装言語 TypeScript (Node.js) MCP SDK と型安全な実装の両立
トランスポート stdio VS Code Copilot の標準構成に合う
設定ファイル YAML (config.yaml) コメント付きで調整しやすい
Markdown レンダラ markdown-it HTML 変換を安定して実装できる
FFI koffi JIT FFI で Win32 API を直接呼び出し（ネイティブコンパイル不要）
画像処理 pngjs BMP → PNG 変換（pure JS、軽量）

ツール登録の仕組み

各モジュールは ToolDefinition[] をエクスポートする。.copilot-mcp/src/index.ts がこれらを結合し、toolMap に登録する。

  • コマンド実行系は executor.ts を経由して OS プロセスを起動する
  • ビルド/テスト系ツールは parsers.ts でエラー・テスト結果をパースし、formatBuildResult で構造化 JSON（BuildResult）を返す
  • 管理領域書き込み系は .copilot-docs/ と .copilot-work/ への相対パスだけを受け付ける
  • md2html は Markdown ファイルまたはディレクトリを受け取り、.copilot-docs-html/ などの静的 HTML 出力を生成する。Mermaid 図は CDN スクリプトでクライアントサイド描画される
  • 構造化ファイル操作系は JSON、YAML、XML、TOML、INI を読み書きし、JSONPath によるピンポイント操作も提供する
  • ウィンドウ操作系は win32.ts の FFI バインディング層を経由して Win32 API を呼び出す（Windows 限定、条件付き動的 import）

セキュリティモデル

脅威 対策 実装箇所
シェルインジェクション spawn に shell: false を指定し、引数を配列で渡す src/executor.ts
任意コマンド実行 ツールごとの zod スキーマで入力を制限する src/tools/*.ts
管理領域の越境書き込み .copilot-docs/ / .copilot-work/ 配下以外への path を拒否 src/tools/workspace.ts
パストラバーサル ワークスペース外パスを normalize + startsWith(... + sep) で拒否 src/tools/file.ts, src/tools/workspace.ts, src/tools/md2html.ts, src/tools/java.ts, src/tools/structured-file.ts
オプション誤認 git_check_ignore に -- を使い、git_checkout はハイフン始まり target を拒否 src/tools/git.ts
プロトタイプ汚染 __proto__、constructor、prototype キーへのアクセスを禁止 src/tools/structured-file.ts
プロセスハング タイムアウト時に SIGTERM → 3 秒後 SIGKILL src/executor.ts
出力爆発 maxOutputSize 超過時に切り詰めて終了 src/executor.ts
大容量ファイル 構造化ファイル操作に 10MB のファイルサイズ上限を設定 src/tools/structured-file.ts
ウィンドウ操作の範囲制限 クリック座標をクライアント領域内に限定し、範囲外はエラー src/tools/window.ts
HWND 有効性 IsWindow で HWND の有効性をチェックし、無効 HWND はエラー src/tools/window.ts, src/tools/window-screenshot.ts
正規表現インジェクション window_find の titlePattern はリテラルエスケープして部分一致に変換 src/tools/window.ts

設定

config.yaml で以下を変更できる。型が不正な場合はデフォルト値を使う。

項目 デフォルト 説明
timeout 30000 コマンドタイムアウト（ミリ秒）
maxOutputSize 100000 出力上限（文字数）
