markdownlint ルールセットのうち、AIが見落としやすいルールのみ抜粋。

## リスト

- **MD007**: ネストのインデントは **2スペース**（4ではない）
- **MD029**: 順序付きリストの番号は `1. 2. 3.` または全て `1.` で統一

## コードブロック

- **MD040**: フェンスドコードブロックには **必ず言語を指定**する。ハイライト不要なら `text` を使う

## リンク・画像

- **MD034**: URLをそのまま書かない。`<https://example.com>` のように角括弧で囲む
- **MD045**: 画像には必ず **alt text** を付ける: `![説明](image.jpg)`
- **MD051**: フラグメントリンクは GitHub heading algorithm に従う（小文字化・スペースをハイフンに・記号除去）
- **MD059**: リンクテキストに「ここ」「click here」「link」「more」を使わない。リンク先の内容を説明する文言にする

## 見出し

- **MD026**: 見出し末尾に句読点を付けない（`.,;:!。，；：！` が対象。`?` は許可）
- **MD036**: 強調（`**太字**`）を見出しの代わりに使わない。見出し記法を使う

## テーブル

- **MD055**: パイプ `|` は **先頭と末尾の両方** に付ける
- **MD058**: テーブルの前後に **空行** を入れる

## HTML

- **MD033**: インラインHTMLは使わない。Markdown記法で書く

## ファイル

- **MD047**: ファイル末尾は **改行1つ** で終わる
