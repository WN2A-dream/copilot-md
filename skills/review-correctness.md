# スキル: 正確性レビュー（Correctness）

## 適用条件

レビュー対象が大きく、観点別に分割してレビューする場合に使用。

## レビュー観点

| カテゴリ | チェック項目 |
|---|---|
| 正確性 | ロジックが仕様通りか / 境界値・エッジケース / 計算・型変換・文字列処理 / 条件分岐の網羅性 |
| 要件整合 | 計画・preferences.md・UIガイドとの整合性 |
| セキュリティ | OWASP Top 10 に該当する脆弱性 |

## 注意

- 保守性・可読性に関する指摘は行わない
- 正確性に起因しないスタイルの問題は対象外
